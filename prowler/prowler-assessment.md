
# Prowler AWS Security Assessment

## Objective
Assess AWS account configurations against security best practices.

## Tool
Prowler - Open-source cloud security assessment tool.

## Assessment Areas
- IAM security
- S3 bucket permissions
- CloudTrail configuration
- Security group exposure
- MFA configuration
- Logging and monitoring

## Workflow
1. Configure an authorized AWS test account.
2. Install Prowler.
3. Configure least-privilege AWS access.
4. Execute selected AWS security checks.
5. Review PASS, FAIL, and other findings.
6. Prioritize identified security risks.
7. Document remediation recommendations.

## Results
Actual Prowler findings and scan reports will be
added after the assessment is performed.

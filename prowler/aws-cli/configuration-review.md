
# AWS CLI Configuration Review

## Objective
Manually review AWS security configurations.

## Assessment Areas

### IAM
Review users, roles, policies, and MFA settings.

### S3
Review bucket access policies and public access settings.

### CloudTrail
Check whether account activity logging is configured.

### Security Groups
Review inbound and outbound network access rules.
